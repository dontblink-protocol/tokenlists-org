# 安全政策 / Security Policy

## 报告漏洞 / Reporting a vulnerability

发现安全漏洞，请**私下**报告：打开本仓库的 **Security** 页，点 **Report a vulnerability**（GitHub 私密漏洞报告）。

**不要**在公开 issue、PR、讨论区或社交媒体上披露漏洞细节。

If you find a security vulnerability, please report it **privately**: open this repository's **Security** tab and click **Report a vulnerability** (GitHub private vulnerability reporting).

Please **do not** disclose vulnerability details in public issues, pull requests, discussions or social media.

## 请附上 / What to include

- 受影响的文件或页面 / Affected files or pages
- 复现步骤 / Steps to reproduce
- 可能的影响 / Potential impact

## 说明 / Notes

- 我们会尽快查看并回复，但不承诺具体时限。 / We will review and respond as soon as we can, without a fixed timeline.
- 本仓库目前没有漏洞赏金计划，提交报告不代表会获得任何奖励。 / This repository has no bug bounty program; reports are not eligible for rewards.
